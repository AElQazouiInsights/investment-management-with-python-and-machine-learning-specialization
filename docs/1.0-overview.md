# Portfolio Management Fundamentals

## Before You Begin

You should be comfortable with percentages, compound growth, averages, and basic Python variables and functions. The examples use NumPy arrays and pandas Series and DataFrames; pay attention to their asset labels and date indexes as well as their numerical values.

## Module Organization

This module develops the investment decisions behind portfolio construction: how to measure performance and risk, choose asset weights, manage downside exposure, and invest against future liabilities. Work through the four lessons in order; each builds on the financial concepts introduced earlier.

**Core Topics**:

1. [Understanding Returns and Assessing Risks with Value at Risk](./1.1-risks.md): distinguish compounded growth from average returns, measure volatility and drawdowns, and interpret Value at Risk and expected shortfall.
2. [Fundamentals of Portfolio Optimization](./1.2-optimization.md): combine expected returns and covariance, construct efficient portfolios, and examine how constraints and cash financing change the allocation.
3. [Strategies Beyond Diversification](./1.3-diversification.md): investigate changing correlations, dynamic risk allocation, and simulated investment paths.
4. [Fundamentals of Asset-Liability Management](./1.4-alm.md): value future obligations, analyze interest-rate exposure, and compare portfolios designed around funding goals.

## What You Should Be Able to Explain

- Why arithmetic averages, compounded growth, and risk-adjusted performance answer different questions.
- How covariance, constraints, and cash financing affect portfolio weights and risk.
- How rebalancing and dynamic allocation change the path of wealth and downside exposure.
- Why a portfolio designed to fund a liability can differ from one designed to maximize asset returns.

## Working Through the Examples

Start with each financial explanation and worked calculation, then run the Python example to check the result. Use the suggested experiments to see which conclusions change when the assumptions change. The goal is to understand the investment problem and interpret the evidence.

Examples run in your browser. Within a lesson, run dependent cells in order: they share Python variables, and later examples often reuse earlier data and estimates. Reloading the page clears that Python session, although saved code edits remain. Use **reset editor** to return an edited cell to the lesson's current example.

Historical estimates describe the supplied data sample; simulated outcomes describe the stated model. Neither is a promise of future performance. Keep the return horizon, units, investment constraints, and financing assumptions consistent when comparing results.

# Advanced Portfolio Construction and Analysis

The [fundamental lessons](./1.0-overview.md) introduced portfolio decisions with supplied return and risk inputs. We now examine where those inputs come from, what they assume, and how uncertainty changes an allocation. The sequence moves from explaining returns to estimating risk, updating expected returns, and allocating risk budgets.

## Before You Begin

You should be able to calculate portfolio returns and volatility, distinguish total from excess returns, and work with long-only, fully invested constraints. Review [Fundamentals of Portfolio Optimization](./1.2-optimization.md) if these ideas are unfamiliar.

The examples use pandas date indexes and asset labels, covariance matrices, matrix multiplication, and basic regression. You do not need to implement the numerical solvers yourself, but you should be able to explain their objectives, inputs, and constraints.

## The Learning Sequence

1. **[Style and Factor Exposures](./2.1-style-factors.md)** asks what exposures help explain a portfolio's returns. Interpret regression coefficients and alpha, distinguish factor analysis from constrained style replication, and examine how weighting rules change exposures.
2. **[Covariance Matrix Estimation for Portfolio Construction](./2.2-covariance.md)** asks how much structure to impose on noisy risk estimates. Compare sample, constant-correlation, shrinkage, and factor-based estimates; then examine time-varying volatility and allocations formed from prior observations.
3. **[Black–Litterman: Reference Portfolios, Views, and Uncertainty](./2.3-black-litterman.md)** begins with sample-mean uncertainty and structured expected-return targets, then asks how a reference allocation and explicit views can inform expected excess returns. Separate uncertainty about means from return covariance, then choose an allocation under stated constraints.
4. **[Robust Portfolio Construction: Diversification and Risk Budgets](./2.4-robust-portfolios.md)** asks how capital concentration differs from risk concentration. Derive Euler contributions, construct positive risk budgets, and evaluate sampling sensitivity, drift, turnover, and self-financed costs.

These chapters address connected decisions. A factor model describes exposures; a covariance estimate describes modeled risk; Black–Litterman updates beliefs about expected returns; a portfolio rule converts selected inputs into weights. Their outputs have different meanings even when they use the same return data.

## What You Should Be Able to Do

- Interpret estimated exposures without treating them as observed holdings or proof of investment skill.
- Explain the structural assumptions behind a covariance estimator and test their effect on allocations.
- Express views with consistent horizons, units, asset labels, and uncertainty.
- Distinguish conditional return covariance, uncertainty about expected means, and predictive covariance.
- Reconcile capital weights with signed Euler risk contributions and requested risk budgets.
- Compare portfolios using common assets, information dates, constraints, rebalancing rules, and costs.

## Working Through the Examples

Read each worked calculation before running its Python cell. Run dependent cells in order, and start each chapter with its own setup and data-loading cells. Historical observations are usually monthly decimal returns; hypothetical examples state their reporting horizon. Check any conversion to annualized quantities before combining inputs.

Use the interactive experiments to change one assumption at a time. Before moving a slider, predict which quantities should change and which should remain invariant. Then explain the result using the model, rather than only the appearance of the chart.

## Bring the Decisions Together

Finish with **[Comparing Portfolio Decisions: A Capstone](./2.5-capstone.md)**. Extend the three-industry illustration from Chapter 2.3 to compare equal weighting, a reference allocation, minimum variance, equal risk contribution, and Black–Litterman. Report both the modeled allocation decision and its subsequent performance, including the trading needed to maintain it.

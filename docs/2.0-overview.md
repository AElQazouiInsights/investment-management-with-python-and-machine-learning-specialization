# Advanced Portfolio Construction and Analysis

[Course 1](./1.0-overview.md) introduced portfolio construction and basic historical estimates. How reliable are those estimates, and how do they affect allocations? This course examines factor exposures, risk and return estimates, and portfolio risk budgets.

## Before You Begin

You should be able to calculate portfolio returns and volatility, distinguish total from excess returns, and work with long-only, fully invested constraints. Review [Fundamentals of Portfolio Optimization](./1.2-optimization.md) if these ideas are unfamiliar.

The examples use pandas, covariance matrices, matrix multiplication, and basic regression. You should be able to explain an optimizer's objective and constraints without implementing the solver yourself.

## The Learning Sequence

Work through four core chapters, then complete the capstone.

1. [Style and Factor Exposures](./2.1-style-factors.md): interpret regression coefficients, alpha, style replication, and the effect of weighting rules.
2. [Covariance Matrix Estimation for Portfolio Construction](./2.2-covariance.md): compare sample, structured, and shrinkage estimates, then examine time-varying risk.
3. [Black–Litterman: Reference Portfolios, Views, and Uncertainty](./2.3-black-litterman.md): study mean uncertainty and shrinkage targets, then combine reference-implied returns with explicit views.
4. [Robust Portfolio Construction: Diversification and Risk Budgets](./2.4-robust-portfolios.md): distinguish capital from risk concentration and account for estimation sensitivity, turnover, and costs.
5. [Comparing Portfolio Decisions: A Capstone](./2.5-capstone.md): compare five allocation rules on one three-industry universe, including input sensitivity and rebalancing costs.

## What You Should Be Able to Do

- Interpret factor exposures and explain the assumptions behind a covariance estimate.
- Compare sample-mean, equal-return, equal-Sharpe, factor-based, and reference-implied expected returns.
- Express views consistently and distinguish mean uncertainty from return risk.
- Calculate risk contributions and compare them with capital weights.
- Evaluate allocations using common dates, constraints, rebalancing rules, and costs.

## Working Through the Examples

Read each worked calculation before running the code. Start each chapter with its setup cells and run dependent examples in order. Check return units and annualization before combining inputs.

Change one assumption at a time. Before moving a slider, predict what should change; then use the calculation to explain what happened.

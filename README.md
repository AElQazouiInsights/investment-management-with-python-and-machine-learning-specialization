# Investment Management with Python & Machine Learning Specialization

After earning a specialization in **Investment Management with Python and Machine Learning** from EDHEC Business School ([**`Credential ID: WUTZABL42PW8`**](https://www.coursera.org/account/accomplishments/specialization/WUTZABL42PW8)), I compiled key financial and mathematical concepts into a Python module. This project is documented in Jupyter notebooks and here on Vitepress.

The main goal of this project is to provide an accessible, structured, and practical approach to modern investment strategies and portfolio management techniques. It aims to bridge the gap between academic theory and real-world application, enabling users—from students to professional investors—to implement and test various investment strategies using Python.

The content spans several core areas:

- **Fundamental Analysis**: Introducing basic concepts such as returns calculations and risk assessments.
- **Quantitative Methods**: Covering advanced statistical and mathematical techniques to optimize portfolios and manage risks effectively.
- **Machine Learning Applications**: Demonstrating how machine learning can be applied to enhance predictive accuracy in investment decisions.
- **Interactive Learning**: Each module includes interactive Jupyter notebooks that allow users to experiment with real data, tweak parameters, and observe the outcomes in real-time.

This educational toolkit is not just a passive learning resource but an active framework for engaging with and mastering the complexities of financial markets through technology.

- Historical proxy: `get_total_market_index_returns()` now uses previous-month capitalization weights and drops the first month without a lagged observation. It requires complete, consecutive monthly data and matches the diversification lesson's proxy convention; it is not an official market index. `historical_drawdown()` selects complete calendar years after constructing that proxy and restarts wealth/peaks at one. Its cash rate is a hypothetical constant effective annual assumption, also used for the Sharpe benchmark.
- Drawdown allocator: `ldi_drawdown_allocator()` delegates to `ldi_drawdown_backtest()`, which reuses the CPPI accounting engine with initial wealth one and `m=1/maxdd`. All diagnostic frames retain return-endpoint labels: `Floor value` and `Prior peaks` describe the beginning decision; `Wealth`, `Peaks`, `Next floor`, and `Drawdown` describe the ending state. Initial wealth is included in peaks. `maxdd` is a requested limit, not a guarantee; comparisons use matched rate scenarios for long bonds and rolled cash.
- Floor allocator: `ldi_floor_allocator()` now requires the **full** unit-ZCB price path, including time zero and maturity (one more row than returns). The hedge returns must match its price ratios; allocations use beginning prices. `ldi_floor_backtest()` exposes wealth, floor PVs, beginning-period monetary cushions, weights, returns, and sampled breaches. Depleted accounts stay zero and later account returns are undefined. The funded `m<=1` reserve argument and higher-multiplier gap risk are tested separately.
- Glide-path convention: `ldi_glidepath_allocator()` applies `start` to the first interval and `end` to the last interval; the last target is set one observation interval before the horizon. A single interval uses only `start`. The schedule is identical across scenarios and supports declining, constant, and increasing targets. Charts use the shared `seriesOptions.step` setting rather than chart-specific Vue branches.
- Duration: `mac_duration()` uses an effective discount rate per cash-flow index unit and returns time in those units. It supports nonnegative named streams and the same rate-label alignment as `present_value()`. A single valuation returns a float; multiple valuations return a labeled Series. Convert nominal annual YTM before using a year-based index.
- Quote-aware sensitivity: `bond_sensitivity()` reports price, Macaulay/modified duration, normalized convexity, dollar duration, and DV01 for nominal or continuous annual quotes. `show_duration_echart()` serves both duration experiments; its default is still nominal, and controls explicitly bind the quote convention. Dollar duration is minus the derivative with respect to the decimal annual quote; DV01 is the corresponding positive first-order 1-bp loss estimate.
- Widget code generation: `src/widget-controls.js` holds the shared helper/parameter registry, control-value handling, and Python-call builder used by `Editor.vue`; the routing tests exercise these functions directly. The worker exports Python keywords separately from display labels and snapshots scalar callback arguments, including `widgets.fixed()` values. Reruns replace control contexts; queued callbacks from retired contexts are ignored. Python `None` and boolean literals are preserved.
- Fixed-mix returns: `ldi_mixer()` requires complete simple-return frames with identical ordered dates and scenario labels, plus finite long-only beginning-period weights. Convert exact-GBM log returns with `expm1`. `summary_stats_terminal()` retains its historical row labels, adds unconditional mean shortfall, and reports target attainment/surplus when a finite target is supplied. Its historical `Mean wealth std` label means sample standard deviation across terminal outcomes; `Exp shortfall` means conditional shortfall relative to the supplied threshold, not percentile CVaR.
- Coupon-bond price paths: `bond_price()` and `cir_bond_price()` now return full **post-payment** prices, including zero after final redemption, with maturity/frequency metadata. `bond_returns()` adds coupons and redemption once; it needs explicit maturity if that metadata is unavailable. Observation indices are consecutive steps beginning at zero. A sliced, shorter price window retains the bond's actual maturity. The scalar-price return helper measures annualized terminal wealth with coupons held at zero interest, not YTM.

Legacy `tracking_error()` is Euclidean fit distance, not active-return standard deviation. Capitalization weighting uses the last training date for the next return; capped equal weights redistribute only within remaining capacity. Euler attribution distinguishes marginal/component volatility and relative risk shares; signed hedge contributions are retained, while `enc()`/`encb()` require nonnegative normalized shares for their concentration-count interpretation. `encb()` is not a count of independent factors. The historical comparison uses 30 industries, 60-month estimation windows, 288 common evaluation months, drift-aware turnover, and fees financed by the portfolio. The input bridge uses a 32-bit UTF-8 length and a consumer-reset ready flag, preserving responses above 255 bytes and rejecting input over 1024 bytes without partial writes.
